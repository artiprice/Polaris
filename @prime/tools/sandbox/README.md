# Polaris OpenShell sandbox image

Build this local image from WSL2 at the repository root with `bash @prime/tools/sandbox/build-wsl.sh`. The script resolves the NVIDIA NGC Ubuntu 24.04 base to its current immutable OCI digest, assembles an allowlisted temporary Docker context, builds the workspace guest binary with Rust 1.99, copies that toolchain into the final sandbox for in-sandbox Cargo checks, then prints the context SHA-256, local Docker image content ID and checks `/usr/bin/polaris-guest --protocol-version` inside the image. The context keeps the locked workspace manifests and build entrypoints Cargo needs, but copies full source trees only for `polaris-guest` and its pinned path-dependency closure. It never sends the full workspace, target outputs, local credentials, or machine configuration to Docker. The output image tag is `polaris-sandbox:p2` unless `POLARIS_SANDBOX_TAG` is set. The script does not push the image.

Use the printed `image_id` (`sha256:<64 hex>`) in the blueprint's `components.sandbox.image`; the blueprint digest then binds that immutable local image reference.
